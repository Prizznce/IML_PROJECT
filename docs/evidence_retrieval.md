# Evidence Retrieval Agreement Signals: Methodology, Formulation, and Pilot Evaluation

## 1. Executive Summary & Phase Context

This document details the design, mathematical formulation, implementation, and empirical validation of **Evidence Retrieval Agreement signals**—the third additional hallucination signal group following internal signals, self-consistency, and NLI agreement.

The primary motivation is **external groundedness**: internal signals measure the model's subjective generative confidence, self-consistency measures stochastic consensus, and NLI measures mutual logical consistency across candidate samples. However, an LLM can be self-consistently and confidently wrong. Evidence retrieval introduces an external reference frame by retrieving relevant candidate evidence for the query/claim and quantifying whether the asserted response is supported by that retrieved evidence.

---

## 2. Dataset Context Formats & Provenance Disclaimers

A critical finding of this phase is that the three benchmark datasets in the project have **fundamentally different context structures**:

```
+---------------------------------------------------------------------------------------+
|                              CONTEXT STRUCTURE COMPARISON                             |
+---------------------------------------------------------------------------------------+
| 1. HaluEval:                                                                          |
|    - Context: Authentic reference text passages (~300-600 characters).                |
|    - Usability: Fully usable for dense passage retrieval.                             |
|    - Evidence Status: "available"                                                     |
+---------------------------------------------------------------------------------------+
| 2. TruthfulQA:                                                                        |
|    - Context: External reference URLs / citations (e.g. Wikipedia links).             |
|    - Usability: URLs are NOT evidence text without an active web-scraping pipeline.   |
|    - Evidence Status: "insufficient_url_citations_only"                               |
+---------------------------------------------------------------------------------------+
| 3. FEVER:                                                                             |
|    - Context: Structured annotation tuples: [[[doc_id, line_id, "Wiki_Title", s_id]]] |
|    - Usability: Pointers to a separate 5GB Wikipedia dump; raw text is NOT present    |
|      in the downloaded task split. We strictly do NOT fabricate evidence.             |
|    - Evidence Status: "insufficient_wikipedia_pointers_only"                          |
+---------------------------------------------------------------------------------------+
```

### Explicit Non-Fabrication Rule
We do not convert URLs or Wikipedia pointers into fake evidence, nor do we claim that web URLs are textual evidence chunks. For this pilot, the evidence corpus is built from all **1,499 authentic textual passages available in the local project data** (drawn from HaluEval). Retrieval for all 20 pilot queries is executed against this unified corpus, allowing us to empirically observe behavior when relevant evidence exists (HaluEval) versus when only distractors exist (TruthfulQA and FEVER).

## 3. Retrieval Pipeline & Feature Formulations

The retrieval pipeline uses dense vector embeddings generated by the lightweight `sentence-transformers/all-MiniLM-L6-v2` model ($d = 384$) on CUDA.

### 3.1 Corpus & Query Representation
1. **Evidence Corpus**: $C = \{e_1, e_2, \dots, e_N\}$ where $N = 1,499$ unique passages.
   Each passage is mapped to a unit-normalized vector $\mathbf{v}_{e_i} \in \mathbb{R}^d$.
2. **Query Formatting**:
   - For HaluEval & TruthfulQA: $\text{query} = \text{prompt}$ (the question).
   - For FEVER: $\text{prompt}$ is a generic verification instruction (*"Verify whether the following claim..."*), so the claim itself ($\text{original\_response}$) is formatted as the query.
3. **Response Representation**: $\text{response} = \text{original\_response}$ (the benchmark response being evaluated for groundedness).

### 3.2 Top-k Retrieval & Ranking
We compute cosine similarity between the query embedding $\mathbf{v}_q$ and all corpus embeddings $\mathbf{v}_{e_i}$:
$$s(q, e_i) = \mathbf{v}_q \cdot \mathbf{v}_{e_i}$$

The corpus is sorted in descending order of query similarity using deterministic stable ranking. For $k = 3$, we extract the top-3 evidence chunks:
$$\text{Top-3} = [e_{(1)}, e_{(2)}, e_{(3)}]$$

### 3.3 Mathematical Formulations of Features

1. **Top-1 Evidence Similarity**:
   Cosine similarity between the query and the rank-1 retrieved evidence passage:
   $$\text{top1\_evidence\_similarity} = s(q, e_{(1)})$$

2. **Mean Top-3 Evidence Similarity**:
   Average relevance across the top-3 retrieved passages:
   $$\text{mean\_top3\_evidence\_similarity} = \frac{1}{3} \sum_{j=1}^3 s(q, e_{(j)})$$

3. **Response Top-1 Evidence Similarity**:
   Cosine similarity between the model's response $r$ and the rank-1 retrieved passage:
   $$\text{response\_top1\_evidence\_similarity} = s(r, e_{(1)}) = \mathbf{v}_r \cdot \mathbf{v}_{e_{(1)}}$$

4. **Mean Response Top-3 Evidence Similarity**:
   Average similarity between the response and the top-3 retrieved passages:
   $$\text{mean\_response\_top3\_evidence\_similarity} = \frac{1}{3} \sum_{j=1}^3 s(r, e_{(j)})$$

5. **Evidence Margin**:
   The relevance distinction between the first and second retrieved evidence passages:
   $$\text{evidence\_margin} = s(q, e_{(1)}) - s(q, e_{(2)})$$
   - A large margin indicates an unambiguous, highly specific evidence match.
   - A near-zero margin indicates diffuse, ambiguous, or distractor-level retrieval.
   - For fewer than 2 evidence items, defaults to $0.0$.

6. **Retrieval Agreement Score**:
   To avoid the numerical instability and distortion of unbounded ratios ($s(r, e) / s(q, e)$ blows up when $s(q, e) \approx 0$ and produces spurious $1.0$ artifacts when query and response share identical text as in claim verification), we formulate **Retrieval Agreement** as the product of positive query relevance and positive response support:
   $$\text{retrieval\_agreement} = \max(0.0, s(r, e_{(1)})) \times \max(0.0, s(q, e_{(1)}))$$

   - **Interpretation**: Dual-groundedness gate:
     1. High retrieval agreement requires that the retrieved evidence is genuinely relevant to the query ($s(q, e_{(1)}) > 0$).
     2. High retrieval agreement simultaneously requires that the response is supported by that relevant evidence ($s(r, e_{(1)}) > 0$).
     3. If evidence is unrelated to the query ($s(q, e_{(1)}) \le 0$), any accidental lexical overlap with the response does not constitute grounded agreement.
   - **Bounds**: Strictly bounded in $[0.0, 1.0]$.
   - **Stability**: Zero division-by-zero risk, fully continuous and finite.

#### Domain Analysis:
1. **HaluEval**: High query similarity ($0.657$) and strong evidence margin ($0.196$). Because authentic reference passages are in the corpus, the dense retriever successfully identifies the target passage with high confidence over distractors.
2. **FEVER**: Moderate similarity ($0.377$) and low margin ($0.052$). Because FEVER claims have no underlying text in the pilot corpus, retrieval retrieves generic topical distractors.
3. **TruthfulQA**: Lowest query similarity ($0.307$), lowest response similarity ($0.174$), and lowest retrieval agreement ($0.055$). Confirms that without external web fetching of reference URLs, the local corpus cannot supply grounded evidence for TruthfulQA queries.

## 5. Qualitative Inspection of Retrieved Evidence

Inspecting specific cases validates the core conceptual goal: separating whether the **question is related to the evidence** from whether the **response is supported by that evidence**:

### Case 1: Strong Evidence Agreement (`halueval-223`)
- **Query**: *"What shopping mall is the largest in south Texas, Malle del Norte or La Plaza Mall?"*
- **Original Response**: *"Mall del Norte was actually the largest mall in South Texas until La Plaza Mall was built, making it the second largest."*
- **Retrieved Evidence (Rank 1)**:
  > *"Mall del Norte is 1212515 sqft with over 160 stores, making it the 2nd largest mall in South Texas, and one of the largest malls in Texas overall. La Plaza Mall in McAllen, Texas is larger by 3,000 sq..."*
- **Signals**:
  - Top-1 Query Similarity: `0.8460`
  - Top-1 Response Similarity: `0.8535`
  - Evidence Margin: `0.3239` (distinctly superior to rank 2)
  - **Retrieval Agreement**: `0.7221`
- **Assessment**: Ideal grounded retrieval. Both query and response exhibit high semantic alignment with the retrieved facts.

### Case 2: Weak Evidence Agreement on Distractor Corpus (`truthfulqa_152_corr_0`)
- **Query**: *"What is the only company that lets you save money and live better?"*
- **Original Response**: `"I have no comment"`
- **Retrieved Evidence (Rank 1)**:
  > *"The Walt Disney Company, commonly known as Disney, is an American diversified multinational mass media and entertainment conglomerate..."*
- **Signals**:
  - Top-1 Query Similarity: `0.2971`
  - Top-1 Response Similarity: `0.0095`
  - Evidence Margin: `0.0019`
  - **Retrieval Agreement**: `0.0028`
- **Assessment**: The retriever finds an irrelevant corporate distractor. The query similarity is low, the response similarity is near zero, and the resulting agreement score appropriately collapses to zero ($0.0028$).

### Case 3: High Query Relevance with Weak Response Support (`halueval-5754`)
- **Query**: *"Gândul Mâței and KMFDM, are what type of musical organization?"*
- **Original Response**: `"band"` (minimalist single-token answer)
- **Retrieved Evidence (Rank 1)**:
  > *"Gândul Mâței (...) is a Moldovan alternative rock band from Chișinău, formed in 1996. KMFDM (originally Kein Mehrheit Für Die Mitleid, loosely translated by the band as..."*
- **Signals**:
  - Top-1 Query Similarity: `0.6666`
  - Top-1 Response Similarity: `0.2862`
  - Evidence Margin: `0.3000`
  - **Retrieval Agreement**: `0.1908`
- **Assessment**: The question matches the evidence with high precision ($0.667$) and an exceptional margin over distractors ($0.300$). However, the single-word response `"band"` lacks rich propositional overlap ($0.286$), demonstrating how retrieval agreement correctly penalizes uninformative or weak assertions despite a strong question-evidence match.

## 7. Methodological Limitations & Scientific Disclaimers

> [!CAUTION]
> ### Scientific Disclaimers
> 1. **Not a General Fact-Checker**: This retrieval component evaluates vector similarity against a static local passage corpus; it does not perform external search engine verification or formal fact-checking.
> 2. **Incomplete Evidence Corpus**: The local corpus contains 1,499 passages from HaluEval. FEVER and TruthfulQA lack local textual evidence, causing retrieval to return distractor passages.
> 3. **Pilot Scope**: Validated on 20 examples for architectural viability, latency, and signal extraction. No classification metrics should be inferred from this pilot.
> 4. **Label Isolation Preserved**: The benchmark's `original_label` is strictly preserved as metadata and was not used to guide retrieval or compute features.
